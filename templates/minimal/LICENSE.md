# Minimal template

This template uses **no third-party LaTeX class** — it is a plain `article`
document plus `eso-pic`, `fontspec`, `paracol`, `multicol` and
`fontawesome5`, all of which come from the standard TeX distribution.

The **fonts** it ships (Lato, Roboto Slab) are covered by
`../LICENSE-FONTS.md`.

The layout is the original author's own; the LaTeX is MIT-licensed with this
repository.
