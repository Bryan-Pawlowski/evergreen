# Vendored fonts

The fonts under `templates/*/fonts/` are redistributed with the templates so
a build is reproducible on any machine — no system font installation and no
TeX distribution required.

| family | files | licence |
|---|---|---|
| Lato | `Lato*.ttf` | SIL Open Font License 1.1 |
| Roboto Slab | `RobotoSlab.ttf` | Apache License 2.0 |
| Source Sans Pro | `SourceSansPro*.otf` | SIL Open Font License 1.1 |

Both the OFL and the Apache 2.0 licences permit redistribution of the font
files unmodified, including in a larger work. The full licence texts ship
with the upstream font packages:

- Lato — https://github.com/google/fonts/tree/main/ofl/lato
- Roboto Slab — https://github.com/googlefonts/robotoslab
- Source Sans Pro — https://github.com/adobe-fonts/source-sans

The font binaries are unmodified copies of the upstream releases.
